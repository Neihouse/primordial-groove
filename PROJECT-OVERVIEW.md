# Primordial Groove - Project Overview

## Project Summary
A modern web platform for the Primordial Groove art collective, designed to showcase events, artists, and foster community engagement in San Francisco's art scene.

## Business Context
Primordial Groove is a San Francisco-based art collective that brings together various art forms through pop-up events, exhibitions, and community gatherings, featuring cutting-edge lighting and LED displays.

## Project Objectives
1. Create a digital presence for the art collective
2. Facilitate event discovery and promotion
3. Showcase artist works and collaborations
4. Build and strengthen community engagement
5. Provide an immersive digital experience aligned with brand values

## Technical Architecture

### Core Technologies
- **Frontend Framework:** Next.js 15.1.5
- **Language:** TypeScript 5.7.3
- **UI Framework:** Mantine v7.16
- **State Management:** React 19.0.0
- **Testing Framework:** Jest 29.7.0

### Development Tools
- Storybook for component development
- ESLint/StyleLint for code quality
- Jest and Testing Library for testing
- Prettier for code formatting

## Target Audience
